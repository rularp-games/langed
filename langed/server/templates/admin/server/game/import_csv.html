Загрузка файла

Если включено, игры с совпадающим названием будут обновлены. Иначе — пропущены.

Формат файла

CSV файл должен содержать заголовок с колонками. Поддерживаемые колонки:

Колонка Обязательная Описание
Название Да Название игры
Анонс Нет Описание/анонс игры
Красные флаги Нет Красные флаги (предупреждения)
Мин. игроков Нет Минимальное количество игроков (по умолчанию: 1)
Макс. игроков Нет Максимальное количество игроков (по умолчанию: 10)
Мин. женских ролей Нет Минимум женских ролей (по умолчанию: 0)
Макс. женских ролей Нет Максимум женских ролей (по умолчанию: 0)
Мин. мужских ролей Нет Минимум мужских ролей (по умолчанию: 0)
Макс. мужских ролей Нет Максимум мужских ролей (по умолчанию: 0)
Игротехники Нет Количество игротехников (по умолчанию: 0)

Моя игра,"Описание игры, которая очень интересная",Насилие,4,8
